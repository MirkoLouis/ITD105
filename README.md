# ITD105

ITD105 Activity and Project Repository: every laboratory exercise and project for the course, one folder each.

| # | Activity | Stack | Location |
|---|---|---|---|
| Case Study | Philippine Tourist Arrivals Forecasting | Python, Streamlit, TensorFlow LSTM, SHAP | [`tourist-arrivals-app/`](tourist-arrivals-app/) |
| Lab | LSTM Crypto Trading Bot (BTC/USDT) | JavaScript, bzUI, hand-written LSTM, Binance public klines | [`lstm-trading-bot/`](lstm-trading-bot/) |
| Final Project | Visualization of Healthcare System Indicators and Health Outcomes: The Philippines vs East Asia and Pacific, 2000 to 2023 | R (ggplot2, pheatmap), Python (Seaborn, scikit-learn, SHAP), Streamlit, World Bank WDI | [`ITD112/healthcare-case-study`](https://github.com/MirkoLouis/ITD112/tree/main/healthcare-case-study) |

The Final Project lives only in the ITD112 repo; it is shared with ITD112 as that course's final project.

Each activity has its own README with setup and run instructions. Shared ignore rules live in the root `.gitignore`. Project-specific ones go in that project's folder.
